# E-commerce Sales Analysis (Excel)

## 📌 Project Overview

This project analyzes e-commerce sales data using Excel.

The dataset includes order-level information such as customer demographics, product details, sales amount, and delivery data.

---

## 🎯 Objectives

- Clean and prepare raw data for analysis
- Identify key sales trends
- Analyze customer segments
- Build an interactive Excel dashboard

---

## 🛠 Tools & Skills

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Data Analysis
- Dashboard Design

---

## 📊 Key Insights

- **Amazon** is the leading sales channel (~35%)
- The majority of revenue is generated by **women** customers (~64%)
- Sales peak in **March** (~1.95M) followed by a steady decline toward year-end
- 92% of orders are **delivered** successfully
- **Adult** women (~34.6%) represent the largest customer group
- **Maharashtra** (~2.99M) is the top-performing state

---

## 📁 Project Structure

- `data/01_raw_data` – original dataset
- `data/02_processed_data` – prepared for analysis (Month, Age Group added)
- `data/03_analysed_data` – pivot tables and calculations
- `dashboard` – final interactive report
- `screenshots` - dashboard's screenshots
